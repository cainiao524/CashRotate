# 訂閱與固定支出記帳 App 需求總結

Oct 28, 2026 · @lowb

## 產品定位與差異化

一款以「每月固定支出」為主角、同時能完整記帳的 App，資料只存在本機與使用者自己的 WebDAV，且上傳前先加密。Android 先上架，面向大眾公開發布。

現有產品各只命中一兩項：

| 產品 | 擅長 | 缺口 |
| --- | --- | --- |
| [ReSubs](https://resubs.app/zh-TW) | 訂閱追蹤、試用轉付費提醒、付款日曆、多種匯入方式 | 同步走自家服務，無 WebDAV；只管訂閱，不記帳 |
| [Wallos](https://alternativeto.net/software/wallos/) + [WallosMobile](https://f-droid.org/packages/com.grappim.wallosmobile.fdroid/) | 開源訂閱追蹤，多幣別 | 必須自架伺服器；不記帳 |
| [Recurring Expense Tracker](https://f-droid.org/packages/de.dbauer.expensetracker) | 開源、Material You、小工具 | 沒有同步說明 |
| 一木記帳、錢跡等 | 完整記帳，一木支援 WebDAV | 訂閱只是附屬的週期帳單 |

差異化三點：

- **固定支出優先**：訂閱、帳單、還款、技術類支出是首頁主角，記帳圍繞它們展開
- **資料自主**：WebDAV 端對端加密同步，無需帳號，無伺服器成本
- **快速上手**：豐富預設庫、首次批次設定、貼上清單由 AI 或規則自動轉換

## 平台與發布策略

Android 先出，目標 API 36（Android 16），用 Flutter 開發以保留之後出 iOS 的路。

- **框架**：建議 Flutter，一套程式碼兩個平台，自適應佈局與多語系成熟；備選 Kotlin Multiplatform + Compose Multiplatform（Android 原生感更好，iOS 工作量較大）
- **最低版本**：建議 Android 8.0（API 26）起，兼顧覆蓋率與通知、背景任務的現代 API
- **目標版本**：Google Play 自 2026 年 8 月 31 日起要求新 App 與更新以 [Android 16（API 36）以上為目標](https://developer.android.com/google/play/requirements/target-sdk)，可申請延到 11 月 1 日
- **上架管道**：Google Play 為主；同時提供 APK（GitHub Releases、F-Droid 或 IzzyOnDroid 若開源）
- **開發者驗證**：Google 要求連側載 App 也須來自[已驗證開發者](https://www.bitdefender.com/en-us/blog/hotforsecurity/google-developer-verification-sideloaded-apps)；巴西、印尼、新加坡、泰國已於 2026 年 9 月實施，2027 年起全球推行。發 APK 前也要完成驗證
- **中國大陸**：無 Google Play，需上國內商店並辦理備案；華為新一代 HarmonyOS 不執行 APK，需另行評估
- **iOS**：Android 穩定後再出，屆時加入 Apple 本機 AI 匯入

## 支出項目類型與欄位

固定支出分五種類型，新增時先選類型，再帶出對應欄位；全部匯總到「每月固定支出」。

| 類型 | 例子 | 特有欄位 | 提醒方式 |
| --- | --- | --- | --- |
| 訂閱 | Netflix、iCloud、Game Pass、健身房 | 方案、試用結束日、自動續訂、取消連結 | 續訂前、試用轉付費前 |
| 帳單 | 手機、寬頻、水電瓦斯、房租 | 預估金額 / 實際金額、合約到期日 | 繳費日前、合約到期前 |
| 還款 | 信用卡、房貸、車貸、分期、親友借款 | 總期數、剩餘期數、剩餘本金、結帳日 + 繳款日 | 出帳時、繳款日前，最後一期自動停止 |
| 保險與年費 | 保險、牌照稅、信用卡年費、會費 | 保單號、到期日、年繳攤提成月 | 提前 30 天起多段提醒 |
| 定期轉出 | 孝親費、定期定額、儲蓄險 | 轉入對象 / 帳戶 | 轉帳日前；報表上與消費分開 |

**共通欄位**：名稱、金額、幣別、週期（日 / 週 / 月 / 雙月 / 季 / 半年 / 年 / 自訂間隔）、下次扣款日、已付至日期、付款帳戶、分類、標籤、狀態（啟用 / 暫停 / 已取消）、備註、價格歷史。

**技術類支出（伺服器與域名分類）**

- 域名：域名、註冊商、首年價與續費價、已付至年份、自動續費開關、寬限期
- VPS：服務商、機器名稱 / IP 備註、配置（核心、記憶體、流量）、機房位置、計費週期（含按小時）
- 遊戲伺服器：遊戲、服務商或「架在某台 VPS 上」（關聯避免重複計算）、暫停狀態
- 多幣別與自動匯率，總覽統一換算成主要幣別；年付自動攤提為每月成本

**合租分攤**：總價、分攤人數、我的份額，可記錄誰已轉帳給我。

**價格階段（首期優惠與續費價）**

每個項目的價格是一串「階段」，而不是單一金額；最後一個階段是長期價格。同一機制涵蓋域名首年優惠、VPS 首期折扣、影音前 3 個月特價、電信綁約優惠、免費試用（價格 0 的階段）。

| 例子 | 階段 1 | 階段 2（長期） |
| --- | --- | --- |
| .com 域名 | 首年 1 美元，1 期 | 續費 15 美元 / 年 |
| VPS 首期折扣 | 首 3 個月 5 美元 / 月 | 之後 8 美元 / 月 |
| 影音試用 | 7 天 0 元 | 390 元 / 月 |
| 電信綁約 | 前 24 個月 499 元 | 合約後 599 元 |

- **新增時**：預設只填一個價格；勾選「首期優惠」才展開「優惠價 + 持續幾期 + 續費價」，續費價必填，避免之後被嚇到
- **提醒**：階段切換前的那次續訂提醒特別標示「下次續費將從 1 美元變為 15 美元」，並附「去比價 / 轉移」的取消連結
- **金額顯示**：列表與總覽顯示本期實付金額，詳情同時顯示「穩定後每月成本」；未來現金流預測依各期實際階段計算
- **漲價**：服務商公告漲價時，新增一個從某日起生效的階段，舊紀錄不受影響，並寫入價格歷史
- **實付與預期不同**：確認扣款時金額不一致，詢問「只這一次」還是「更新之後的價格」
- **一次付多年**：域名續 3 年記為一筆付款，「已付至」日期推進 3 年；現金流顯示當次整筆支出，月度成本報表則攤提成每月
- **幣別**：階段價格以原幣記錄，每次實付時按當日匯率換算並保存，匯率變動不改寫歷史

**外幣項目自動換算成主要幣別**

外幣項目以原幣價格為準，新增當下就顯示換算後的主要幣別金額；實際扣款後再以帳單上的金額校正。適用 AI 訂閱（多為美元）、pixivFANBOX 贊助（日圓）、海外 VPS 與域名等。

| 時點 | 顯示 | 用的匯率 |
| --- | --- | --- |
| 新增 / 編輯時 | 輸入 US$20 → 即時顯示「≈ NT$ 652，匯率 32.59，2026-10-27 更新」 | 最新快取匯率 |
| 列表、總覽、預測 | 主要幣別為大字，原幣為小字（NT$ 652 · US$20） | 每日更新的匯率，估算值標「≈」 |
| 確認付款時 | 預填估算的主要幣別金額，可改成帳單上的實際金額 | 依實付金額反推實際匯率，存入交易，不再變動 |

- **預設幣別**：預設庫帶入服務的計價幣別（AI 訂閱 USD、FANBOX JPY），使用者不必每次選
- **海外交易手續費**：每個付款帳戶可設手續費率（如信用卡海外交易手續費），估算時一併計入並註明
- **學習實際匯率**：同一張卡多次實付後，算出平均加價幅度，之後的估算自動採用
- **本幣計價的服務**：有些服務在商店以本地幣別扣款，此時項目直接用主要幣別，不換算
- **符號歧義**：「¥」可能是日圓或人民幣，「$」可能是多種元；依預設庫、使用者地區判斷，無法判斷時讓使用者選；AI 匯入同樣適用（「20 刀」= USD）
- **更換主要幣別**：所有總覽與報表重新換算；已確認交易保留當時匯率
- **離線**：使用最後一次快取的匯率並顯示日期；可手動指定某幣別匯率
- **小數位**：依幣別顯示（JPY、TWD 不顯示小數），內部仍以最小單位整數儲存

可選的主要幣別：亞太全部加 USD、EUR，共 41 種，完整清單與顯示規則見 支援幣別。

**遊戲道具（如 CS2）**：不做專屬功能。購買記支出、出售記收入（分類「道具出售」，報表可設為不計入工作收入），用「CS2」標籤看淨花費；Steam 錢包為儲值帳戶。想算資產者可選用「手動估值資產」帳戶（v2）。

## 預設庫

預設庫是一份可線上更新的 JSON，v1.0 收錄 200～300 項，供首次設定、新增搜尋和 AI 匯入辨識共用。

**每項資料**

```json
{
  "id": "netflix",
  "name": { "zh-Hant": "Netflix", "zh-Hans": "奈飞", "en": "Netflix" },
  "aliases": ["網飛", "网飞", "NF", "netflix.com"],
  "category": "streaming",
  "type": "subscription",
  "defaultCycle": "monthly",
  "regions": ["global"],
  "plans": [{ "id": "standard", "name": "標準" }],
  "remindDays": 3,
  "cancelUrl": "https://www.netflix.com/cancelplan",
  "color": "#E50914",
  "fields": []
}
```

- **aliases**：辨識關鍵，含簡繁、俗稱、縮寫、網域、銀行帳單上的扣款商號
- **type + defaultCycle**：AI 或使用者沒寫週期時自動補上
- **regions**：依使用者地區顯示，如電信商只在當地出現
- **fields**：特殊類型的額外欄位（域名、VPS、還款期數）

**收錄範圍**：全球通用約 120 項（影音、音樂、雲端、軟體、AI、遊戲平台、域名商、VPS 商）+ 每個主力地區 30～50 項（電信、寬頻、本地服務、帳單）+ 約 30 個無品牌模板（房租、水電、房貸、信用卡、保險、孝親費等）。

**價格**：方案名稱內建，價格不內建或僅標「參考價，更新於某年某月」，以使用者首次填寫為準。

**維護**：App 內建一份，啟動時從 GitHub 或 CDN 檢查更新；社群經 GitHub 提交新服務與別名；使用者自訂項目與手動修正的別名存在個人資料中並隨 WebDAV 同步。

**搜尋**：本機模糊比對，支援中英文、拼音與注音首字母。

**圖示**：預設用「首字母 + 品牌色」圓形徽章，避免商標授權問題；使用者可自行上傳圖示。

## 新增與匯入

目標是新使用者 3 分鐘內建好所有固定支出；勾選預設庫與貼上清單兩條路可混用，結果合併進同一張批次表格。

**首次啟動流程**

1. 基本設定：語言、主要幣別依系統帶入，使用者確認所在地區；WebDAV 放「稍後設定」
2. 選擇匯入方式：勾選常用服務（推薦）／貼上清單／從 WebDAV 備份還原
3. 勾選常用服務：依分類分頁的圖示方塊，頂部搜尋與「已選 N 項」計數，找不到直接新增自訂
4. 批次表格：每行只填方案或金額、扣款日、幣別；其餘用預設值，金額可留空標為「待補」
5. 完成總覽：顯示每月固定支出總額與未來 7 天要付的筆數，並告知已開啟到期提醒

**批次表格的加速設計**：多選後整欄套用（同一扣款日、同一付款帳戶）、鍵盤「下一個」連續輸入、中途離開可續、首頁顯示「還有 N 項待補」。平常的新增入口也提供批次新增（一次加多個域名或 VPS）與「複製項目」。

**貼上即匯入**（來源：備忘錄、Excel、銀行簡訊、帳單 Email、截圖經本機 OCR）

1. 本機遮罩卡號、帳號、證件號
2. AI 或規則把每行擷取成名稱、金額、幣別、週期、日期、類型
3. App 本機比對預設庫別名，補上分類、預設週期、提醒天數
4. 程式驗證格式並找出與現有項目的重複
5. 確認頁：每筆一張可直接修改的卡片，低信心欄位標黃，未辨識的行列在最下方
6. 一鍵批次加入；使用者的修正存成個人別名

**AI 分層**（App 自動選可用的最高層，最後退回規則）

| 優先序 | 層級 | 做法 | 限制 |
| --- | --- | --- | --- |
| 1 | 自帶 AI（v1.0） | 使用者自己的 API Key：OpenAI 相容端點（含自架 Ollama、LM Studio）、Anthropic、Gemini；支援 OAuth 的聚合服務（如 OpenRouter）可登入授權取得金鑰 | 需使用者設定；網頁版會員訂閱帳號通常不能授權給第三方 App 使用 |
| 2 | Android 本機（v1.x） | [ML Kit GenAI Prompt API（Gemini Nano）](https://developer.android.com/blog/posts/ml-kit-s-prompt-api-unlock-custom-on-device-gemini-nano-experiences) | 支援機型有限；無強制 JSON，須驗證輸出 |
| 3 | 規則解析（v1.0） | 正則抓金額、幣別、週期關鍵字 + 預設庫比對 | 句子雜亂時準確率低 |
| iOS 版 | Apple 本機 | [Apple Foundation Models](https://www.atelier-socle.com/en/articles/foundation-models-api-guide) | iOS 26+、iPhone 15 Pro 以上；上下文約 4,096 tokens，需分批 |

使用者可在設定中調整順序；沒有可用的 AI 時自動退回規則解析。不提供開發者代管的雲端 AI，資料只會送到使用者自己選的服務商。

原則：AI 只擷取原文名稱，不負責認品牌或價格（小模型知識有限且會幻覺）；缺的資訊留空不猜。

**本地脫敏（送出前在手機上完成）**

- 自動偵測：卡號（含 Luhn 校驗）、銀行帳號、身分證 / 居留證號、手機號、Email、IP 位址、訂單與合約編號、地址
- 可逆佔位符：替換成保留類型的代號（如 `[卡號1]`、`[IP1]`、`[域名1]`），AI 仍知道是什麼類型；對照表只存本機，回傳後自動還原
- 自訂敏感詞：家人姓名、公司名、自己的域名等，可選替換或保留
- 強隱私模式：金額也換成佔位符，由本機規則解析金額，AI 只判斷名稱、週期與類型
- 送出前預覽：高亮顯示被遮罩的內容，確認後才送；可對某服務商勾選「不再詢問」
- 最小傳送：只送貼上的那段文字，不附帶帳戶餘額或既有資料
- 直連：請求從手機直接發往使用者選的服務商，不經開發者伺服器；App 不保存提示詞與回應
- 金鑰：存於 Android Keystore 加密，預設不同步，可選擇隨 WebDAV 加密同步
- 透明：設定頁列出各服務商資料使用政策的連結，由使用者自行判斷

**他牌匯入**：支援 ReSubs、Wallos、錢跡、MoneyWiz 匯出的 CSV，以及通用 CSV 欄位對應。

## 提醒

提醒是核心價值，必須在國產 Android 機型上也能準時響起。

**提醒種類**

- 續訂前 N 天（每筆可設，支援多段，如 30 / 7 / 1 天）
- 免費試用即將轉付費
- 解約期 / 合約到期（電信綁約、健身房）
- 信用卡：出帳時提醒核對，繳款日前提醒付款
- 還款：每期繳款日前；最後一期後自動停止
- 域名與 VPS：到期前多段提醒 + 寬限期提醒
- 浮動帳單：扣款日當天提醒確認實際金額
- 合租：提醒誰尚未轉帳

**通知操作**：通知上直接「已付款」「延後提醒」；點擊進入該項目詳情。

**可靠性**

- 用不精確鬧鐘（`setAndAllowWhileIdle()` / `setWindow()`）加 WorkManager 每日補檢；不宣告 `USE_EXACT_ALARM`，v1.0 也不用 `SCHEDULE_EXACT_ALARM`（原因見決策分析）
- 引導使用者關閉電池最佳化，針對小米、華為、OPPO、vivo、三星提供各自的設定說明
- 開機與 App 更新後重新排程所有提醒
- 備援：可匯出到系統行事曆（.ics 或寫入行事曆）
- 設定頁提供「發送測試通知」

**日期邊界規則**（必須明確定義並寫測試）：每月 31 日遇小月取當月最後一天、漲價從指定期生效、取消後「已付至」日期前仍顯示為可用、暫停與恢復、退款、時區變更。

## 帳戶與記帳

交易只有三種：支出、收入、轉帳；固定支出綁定付款帳戶後自動入帳，使用者只需記日常變動消費。

**帳戶類型**（每個帳戶各自幣別）：現金、銀行帳戶、信用卡、電子錢包（LINE Pay、PayPal、支付寶等）、儲值（悠遊卡、Steam 錢包、遊戲點數）、投資帳戶（只記餘額）、借貸（應收 / 應付）；v2 加「手動估值資產」。

**信用卡欄位**：額度、已用 / 可用額度、結帳日、繳款日、本期帳單金額、未出帳金額；卡片顯示額度使用率與「距繳款 N 天」。

**餘額正確性**

- 餘額 = 期初餘額 + 所有交易，自動計算
- 對帳：輸入實際餘額，差額自動產生「調整」交易
- 轉帳（含繳卡費、儲值）不計入支出，避免重複計算

**固定支出自動入帳**

- 扣款日到，在綁定帳戶產生「待確認」交易；滑動確認或修改金額
- 信用卡結帳後自動產生繳卡費還款項，金額帶入本期帳單
- 貸款每繳一期自動更新剩餘期數與本金

**長期記帳**：分類與子分類、標籤（跨分類統計，如「日本旅行」「CS2」）、分類月預算與接近上限提醒、依金額 / 帳戶 / 標籤 / 關鍵字搜尋篩選、收據照片與 PDF 附件、資源回收桶（誤刪可還原）、CSV / Excel 匯出。

**快速記帳入口**：桌面小工具一鍵新增、通知欄快速記帳、分享選單（銀行簡訊分享進 App 直接解析）、App 捷徑。

## 同步、加密與安全

資料在本機加密後才上傳 WebDAV，伺服器只看到密文；忘記密碼又沒有復原碼，資料無法找回。

**加密與金鑰**

- 同步密碼經金鑰衍生函數（如 Argon2id）產生金鑰，資料以認證加密（如 AES-256-GCM 或 XChaCha20-Poly1305）加密
- 首次設定產生復原碼，強制使用者確認已抄寫，並清楚警告遺失後果
- 本機資料庫同樣加密，金鑰存於 Android Keystore

**WebDAV 同步**

- 增量同步：按變更紀錄上傳，不每次傳整份
- 衝突處理：以欄位為單位合併，同一欄位以最後修改時間為準，刪除以墓碑紀錄處理；無法自動合併時提示使用者選擇
- 同步狀態：上次同步時間、失敗原因、手動同步按鈕
- 實測服務：Nextcloud、群暉 NAS、堅果雲、InfiniCLOUD
- 本機自動備份 + 歷史版本還原

**App 安全**

- App 鎖：PIN / 生物辨識，可設離開多久後上鎖
- 隱藏金額模式：所有金額顯示為 \*\*\*\*
- 最近使用畫面模糊（`FLAG_SECURE` 可選）
- 當機回報預設關閉，經使用者同意才開啟

## 介面風格與螢幕適配

風格清爽極簡：珠光黑白單色系、大量留白，珠光漸層只用在圖示、首頁總額卡與 Pro 標章，完整深色模式；佈局依視窗寬度（dp）切換，不依裝置型號。

| 視窗寬度級別 | 典型畫面 | 導覽 | 主要佈局 |
| --- | --- | --- | --- |
| Compact < 600dp | 手機直向、摺疊屏外屏 | 底部導覽列 | 單欄列表，詳情為新頁 |
| Medium 600–840dp | 摺疊屏展開、小平板直向、手機橫向 | 側邊導覽軌 | 列表 + 詳情雙欄 |
| Expanded 840–1200dp | 平板橫向、摺疊屏展開橫向 | 側邊導覽軌或抽屜 | 雙欄；首頁為多卡片儀表板 |
| Large ≥ 1200dp | 大平板、桌面模式 | 常駐導覽抽屜 | 三欄（分類 / 列表 / 詳情） |

**適配要求**

- 不鎖定方向與長寬比：以 API 36 為目標時，Android 16 在最小寬度 ≥ 600dp 的螢幕上[會忽略方向與可調整大小的限制](https://android-developers.googleblog.com/2025/01/orientation-and-resizability-changes-in-android-16.html?m=1)，下一版起無法退出
- 摺疊 / 展開、旋轉、進出分割畫面時保留狀態（表單內容、捲動位置、目前頁面）
- 雙欄分隔線對齊摺痕，內容不壓在鉸鏈上；半摺桌面模式上半顯示圖表、下半顯示操作
- 支援分割畫面、自由視窗、實體鍵盤與滑鼠（快捷鍵如 Ctrl+N 新增）、拖放
- 系統字體放大到 200% 不破版；按鈕和卡片不用固定寬度，預留德文、俄文三到四成的文字膨脹
- 觸控目標至少 48dp；文字對比至少 4.5:1；圖表顏色同時以深淺區分
- 桌面小工具提供小、中、大三種尺寸，平板上大尺寸可顯示本月付款日曆

**元件與狀態**：卡片、列表項、表單欄位、按鈕、標籤、圖表皆定義預設 / 按下 / 停用 / 錯誤 / 載入中 / 空狀態；金額統一用等寬數字，支出、收入、轉帳以圖示加文字區分而非只靠顏色。

## 測試計畫：模擬器與實機

模擬器負責覆蓋所有密度與寬度組合，實機負責摺疊、廠商系統與提醒可靠性；每次發版前跑完下列矩陣與清單。

**密度基準**（佈局一律用 dp / sp，圖示用向量圖；啟動圖示提供 adaptive icon 與各密度 mipmap）

| 密度 | dpi | 倍率 |
| --- | --- | --- |
| mdpi | 160 | 1x |
| hdpi | 240 | 1.5x |
| xhdpi | 320 | 2x |
| xxhdpi | 480 | 3x |
| xxxhdpi | 640 | 4x |

**模擬器矩陣**（Android Studio AVD）

| 設定檔 | 寬度級別 | 用途 | Android 版本 |
| --- | --- | --- | --- |
| Small Phone（約 360dp 寬） | Compact | 最窄版面、低 dpi 下文字截斷 | API 26（最低版本） |
| Medium Phone（約 411dp 寬） | Compact | 主流手機基準 | API 36 |
| 手機橫向 | Medium | 橫向雙欄是否正確觸發 | API 36 |
| 7.6" Fold-in with outer display | Compact ↔ Medium | 內外屏切換、摺疊姿態、狀態保留 | API 35、36 |
| Medium Tablet / Pixel Tablet | Expanded | 平板直向與橫向、儀表板 | API 34、36 |

| 自訂 1920×1080 桌面 | Large | 三欄、鍵盤滑鼠、自由視窗 | API 36 |

**用 adb 模擬任意 DPI 與尺寸**（模擬器與實機皆可）

```bash
adb shell wm density 240          # 改密度，模擬 hdpi
adb shell wm size 1440x3120        # 改解析度，模擬大屏
adb shell wm density reset && adb shell wm size reset
adb shell settings put system font_scale 2.0   # 字體 200%
adb shell dumpsys deviceidle force-idle        # 強制進入休眠，測提醒
```

開發者選項另需測：最小寬度、強制允許調整活動大小、啟用自由視窗、偽語系（en-XA 測文字膨脹、ar-XB 測從右到左）。模擬器的擴充控制可調鉸鏈角度測半摺姿態。
