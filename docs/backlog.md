## 2026-11-01 提議、暫不納入 v1.0（之後再決定）

- 假期暫停：多個項目暫停到某日後自動恢復
- 可報帳 / 公司付款標記：不計入個人總額，另外匯出 CSV
- 各卡每月扣款總覽（依結帳日）
- 可分享的摘要圖（可隱藏金額）
- 自訂分類與標籤
- 寫入系統行事曆 / 匯出 .ics（上方已列）
- 刪除項目的回收桶（上方已列）
- 伺服器總覽：VPS IP 備註、機房、到期、月費
- 域名組合：依到期年份，標出未開自動續約與寬限期中的
- API 儲值總覽：本月合計與近 3 個月平均（搭配不固定週期帳單）
- 隱私儀表板：App 何時連過哪些主機（匯率、WebDAV、AI）
- 白話加密說明頁
- 完整資料匯出與「刪除全部資料」
- App 內意見回饋：開啟郵件 App，附版本資訊，不收集分析資料
