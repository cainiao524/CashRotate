# 0012 v1.0 範圍追加（2026-11-01）

- 狀態：已採用（2026-11-01）
- 決策者：專案擁有者（從另一個對話提出的六個功能中勾選）

## 決定

**納入 v1.0**（CLAUDE.md 第 1、9、11、16、17 項，並更新里程碑）：

| 功能 | 里程碑 | 要點 |
| --- | --- | --- |
| 帳單「不固定週期」 | M4 | 新增週期種類 `irregular`，限帳單類型。不展開未來期數、不發扣款前提醒。月成本取付款紀錄的平均，所以要等付款紀錄做好才能做。 |
| 會員升降級 | M4 | 三種處理：立即補差價、剩餘已付時間按比例換算（推移 paidUntil）、下次續費才降級。另外要寫比例換算和日期邊界的單元測試，並在預設庫加入方案層級。 |
| 年曆 / 月曆付費日 | M4 | 直接用現有的 Occurrence。年檢視只用灰階深淺。 |
| 通知大圖示、「前往取消」 | M3 補 | 大圖示用項目的自選圖示或首字母徽章；「前往取消」開啟預設庫的取消連結。 |
| 桌面小工具、Wear OS | M7（新增） | Wear OS 經 Wearable Data Layer 從手機取得資料，手錶不長期保存。 |

**不納入**：家庭主 / 副多人同步與費用分配，記入 `docs/backlog.md`。ADR 0009 的同步格式不必為它調整。

## 影響

- 原本的 M7 打磨與上架改為 **M8**，Google Play Billing 改在 M8 接入（ADR 0007 寫的「M7」指的就是這一步）。
- 執行順序：M3 → M5 → M4 → M6 → M7 → M8。
- 週期種類新增 `irregular`，資料庫的 `cycle_unit` 會多一個值。舊版 App 讀到這個值時不認得，要在 M4 加防護，例如在同步 manifest 註明最低版本。
