# 0018 同步衝突還原與零碎補強

- 狀態：已採用（2026-11-11）
- 決策者：開發者，依 CLAUDE.md「需人判斷者進待處理衝突」、第 3 項與 ADR 0013 的待辦實作。

## 決定

- **衝突：還原被刪的項目**
  - 「刪除後又在另一台被修改」的衝突，改成逐一列出項目，每項可選「還原」或「保持刪除」。
  - **還原的做法**：
    - 已經同步出去的刪除不會撤銷。
    - 改用這台裝置的變更日誌重建項目，套上其他裝置後來的修改，當成一個新項目寫入並同步。
    - 新 id 由舊 id 衍生（UUID v5），兩台裝置各自按還原也只會出現一個項目。
  - **一起還原的資料**：價格階段、已付 / 跳過的各期、漲價紀錄。付款紀錄改指向新項目。待付的各期會重新排程。
  - **不會還原的資料**：刪除前就已移除的價格階段或扣款，保持刪除。判斷依據是：同一台裝置、與項目刪除時間相差 5 秒內一起刪除的，才算「跟著項目一起刪」。
- **首頁同步狀態圖示**：設定好同步後，首頁標題列多一個圖示，四種狀態各有不同圖示和說明，點一下會開啟同步設定。
  - 失敗。
  - 有衝突要決定。
  - 有變更待上傳。
  - 已是最新。
- **鎖定時隱藏「最近使用」縮圖**：開啟 App 鎖後就會套用。
  - Android 13 以上用 `setRecentsScreenshotEnabled(false)`，只遮縮圖。
  - 較舊的版本沒有這個開關，改用 `FLAG_SECURE`，所以也會禁止截圖。設定頁有說明。
- **VPS 按小時計費**：
  - 時薪用小數解析（例如 €0.007/h，比幣別最小單位還小）。
  - 一個月以平均公曆年的十二分之一計，約 730 小時。
  - 編輯頁顯示「每期約 X（N 小時）」，可一鍵帶入金額。這是全時開機的估算，實際金額仍以付款紀錄為準。
- **桌面小工具的圖片圖示**：小工具沿用通知大圖示已存在原生端的圖片（`files/badges`），圖片更新時重繪小工具。
