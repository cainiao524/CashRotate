# 0016 每月收入與固定支出佔比

- 狀態：已採用（2026-11-05）
- 決策者：專案擁有者選擇「只設每月收入，算佔比」，並要求涵蓋所有收入類型。

## 背景

ADR 0010 改用「付款紀錄」取代完整記帳後，App 就沒有任何收入資料，看不出固定支出佔收入多少。

## 決定

- **定位**：收入只用來和固定支出比較，不記每筆入帳，也不計算帳戶餘額。CLAUDE.md 第 10 項「不做一般收支」維持不變，另新增第 19 項。
- **資料**：存在已同步的設定 `income_sources`，每筆為 `IncomeSource`：
  - `type`：11 種收入類型，涵蓋薪資、獎金、接案 / 兼職、自營、租金、投資收益、退休金 / 年金、政府補助 / 津貼、家用 / 生活費、二手 / 道具出售、其他。
  - 其他欄位：名稱（選填）、實領金額與幣別、週期、是否計入比較。
- **週期**：每週、每兩週、月、季、半年、年，用核心的 `Cycle.monthlyEquivalent` 換算成每月金額。
- **預設值**：
  - 獎金預設為年週期，投資收益預設為季週期。
  - 二手 / 道具出售預設不計入比較（不穩定的收入）。
- **計算**：把計入的收入換成主要幣別，和月成本比較，得出佔比與剩餘金額；缺匯率的收入先略過不算。
- **顯示**：
  - **首頁總額卡**：多一行「佔收入 X% · 剩 Y」，固定支出超出收入時用紅字。
  - **分析頁**：新增「收入與固定支出」卡，有收入、剩餘、佔比條和各類型月收入。
  - **隱藏金額模式**：以上金額同樣遮蔽。
