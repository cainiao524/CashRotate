# 0005 預設庫：格式、建置與搜尋

- 狀態：已採用（2026-10-29）
- 依據：CLAUDE.md v1.0 必做第 6 項、需求總結「預設庫」

## 格式

- 原始資料放在 `presets/{global,tw,hk,templates}/*.json`，每個檔案是一個 JSON 陣列。`presets/schema.json` 是給貢獻者的 JSON Schema，方便在編輯器裡提示與檢查。
- 每一項包含：id（永久不變）、三語名稱、別名、分類、類型、預設週期、地區、計價幣別（選填）、方案、提醒天數、取消或管理連結、品牌色、類型專屬欄位群組。
- **不放價格，也不放商標**：品牌在 App 裡只用「首字母 + 品牌色」徽章表示。
- 模板的 id 以 `template-` 開頭，必須有繁中、簡中、英文三種名稱。
- 計價幣別只填「全球都用同一種幣別收費」的服務，例如 AI 訂閱用 USD、pixivFANBOX 用 JPY。沒填代表依當地幣別收費，例如 Netflix。

## 建置（`packages/core/tool/build_presets.dart`）

1. 用 Dart 驗證器逐項解析，這是唯一的權威標準。錯誤訊息會指出是哪個檔案的哪一項、哪個欄位；未知欄位（例如 `price`）會被拒絕。
2. 檢查 id 是否重複，以及**別名是否同時指向兩個項目**。品牌項目不可以用「電費」這類通用詞當別名，否則比對時會有歧義。
3. 依中文名稱和中文別名產生搜尋鍵：完整拼音、拼音首字母、注音首字母。
4. 依 id 排序後輸出 `app/assets/presets/presets.json`，一行一項，方便看 diff。CI 會執行 `--check`，確認內建檔案和原始資料一致。
5. 總數必須在 200～300 之間。首批資料共 264 項：全球 149、只在台灣 49、只在香港 42、模板 36（依地區標籤計算，例如愛奇藝同時計入台灣和香港）。
   - **偏差**：需求寫的是「全球約 120 項」，實際多了約 29 項。這些都是常見的訂閱與技術服務（AI、VPS、網域商、創作者贊助等），刪掉會降低勾選時找得到的機率；總數仍在 CLAUDE.md 規定的 200～300 之內。要縮減的話，可以從 hosting、devtools 兩類開始刪。

## 讀音資料

- 現有拼音套件都多年未更新（lpinyin 最後發布是 2021 年），不符合「仍在維護」的要求。
- 改用 Unicode 官方 Unihan 資料庫的 `kMandarin` 讀音（Unicode 18.0，Unicode License v3）。`tool/update_han_readings.dart` 只截取預設庫用到的字，寫入 `presets/tool/han_readings.tsv`，目前約 450 字。
- 破音字用 `presets/tool/phrase_readings.tsv` 依詞組覆寫，例如音樂、銀行、會員、差餉、地租。
- 讀音只在建置時使用，App 執行時不需要任何讀音資料或套件。

## 搜尋（`PresetSearch`）

- 正規化：轉小寫、全形英數轉半形、移除空白與標點。
- 計分：名稱或別名完全相同 100 > 完整拼音相同 90 > 首字母或注音相同 85 > 名稱開頭相同 80 > …… > 字元依序出現（容錯拼字，例如 ntflx）25。同分時，名稱較短的排前面。
- 可以依地區過濾。`exactMatch()` 給 M6 匯入時辨識品牌用，只有唯一符合時才回傳。
