# 0014 付款紀錄、自動辨識、合租與報表（M4）

- 狀態：已採用（2026-11-02）
- 決策者：專案擁有者選定「讀通知取代記帳」（ADR 0010）、合租主 / 副角色與四組情境、第 18 項只做 8 個低成本功能（ADR 0012）；其餘由開發者依 CLAUDE.md 實作

## 決定

- **資料庫 v3**：`accounts.card_last4`；`transactions` 加 `item_id`、`original_amount_minor`、`original_currency`、`market_fx_rate`。遷移有 v1→v3、v2→v3 測試。
- **付款紀錄**：
  - 每期付款存實付金額。外幣項目可改成帳單實際金額，反推實際匯率並和當日市場匯率比，算出加價（基點）。
  - 每張卡學到的加價取最近 5 筆平均。
  - 實付和預期不同時，問「只這一次」或「更新之後的價格」。
  - 付款方式沿用 `accounts` 表，只當標籤和手續費來源；另有一個不顯示的「未指定」帳戶。
- **通知辨識**（ADR 0010）：
  - 原生 `NotificationListenerService`，只讀使用者勾選的 App；其他 App 只計數「看起來像扣款」的通知，用來建議勾選。
  - Dart 規則解析金額、幣別、商家、末四碼，再對每期應付評分：名稱 0.45，金額 0.35（外幣 0.3），日期 ±5 天 0.15，卡號加減分。
  - 評分 ≥ 0.8 自動記為已付並可撤銷；≥ 0.45 進「待確認」。
  - 重複通知只算一次。同一商家週期性扣款但不在清單中時，提示加成固定支出。
  - 可以把文字分享給 App。
- **不固定週期帳單**：
  - 用 `typeFields.irregular` 標記，不改 enum，也不展開期數、不發扣款前提醒。
  - 月成本 = 近 12 個月付款總額 ÷ max(3, 第一筆付款至今月數)。還沒有付款紀錄時算「待補」。
  - 比對時只看名稱。
- **合租**：
  - `SharingPlan` 分主 / 副角色，均分 / 自訂 / 輪流三種分法。成員的份額可用自己的幣別，可記已付至、加入 / 退出日。
  - 「跟著主揪者漲價」用基準價等比例換算。
  - 月成本、本月待付 / 已付與報表一律只算我的份額。
  - 「別人欠我 / 我欠別人」放在設定頁。舊格式的合租資料讀成「主、均分」。
- **會員升降級**：三種處理方式都寫入 PriceHistory。
  - 立即補差價：按剩餘天數比例算，記成一筆一次性付款。
  - 已付時間換算：推移錨定日與 paidUntil。
  - 下次續費才降級。
- **報表**：
  - **概覽頁**：本月、近 12 月柱狀圖、分類排行、漲價歷史。分類排行取前 5 + 其他，灰階深淺，直接標名稱。
  - **月曆**：格子標首字母徽章與當日合計，點日期列出項目。
  - **年曆**：12 個小月曆，灰階深淺表示月總額。
  - **繪製方式**：全部用一般 widget 畫，不加圖表套件。
  - **平板首頁**：「本月收支 / 固定與變動」兩塊改成「近 12 月」與「分類排行」。
- **CSV 匯出**：
  - **格式**：UTF-8 加 BOM，讓 Excel 正確辨識。
  - **欄位**：日期、項目、金額、幣別、原幣金額、原幣、匯率、付款方式、備註。
  - **存檔**：透過系統存檔選擇器，MIME 為 `text/csv`。
- **第 18 項**：開關都在 `app/lib/features.dart`。
  - 年 / 日成本：年 = 月 × 12，日 = 年 ÷ 365；含各分類。
  - 閒置提醒：每 91 天問一次，在首頁顯示詢問卡，不另發通知。
  - 漲價比較：放在詳情頁與報表。
  - 前往取消：放在詳情頁與通知。
  - 搜尋與篩選：在固定支出列表，可依分類、付款方式、主 / 副角色篩選。
  - 批次編輯：長按多選，可改分類、改付款方式、暫停 / 恢復。
  - 空狀態引導：熱門服務點一下即加入，標成「待補」。
  - App 捷徑：開關關閉，留到 M7。
- **前往取消**：沒有加 url_launcher，原生 `app.cashrotate/links` 頻道只開 http(s) 連結。
- **通知補強（M3）**：
  - **大圖示**：和首頁方塊一致，顯示自選線條圖示或首字母徽章。Kotlin 用 Flutter 內建的 MaterialIcons 字型畫圖示，不傳圖檔；預設單色，使用者開了「服務代表色」才用品牌色。
  - **前往取消**：試用到期和訂閱 / 年費續費的通知加上這個按鈕。

## 與 CLAUDE.md 的偏差

- 閒置提醒只在 App 內詢問，不發推播。
- 「使用者上傳圖片」當圖示：還沒做。方塊與通知目前只支援內建圖示和首字母。
- 首頁的「本月待付 / 已付」改為只算合租中我的份額（原本算全額），和月成本一致。

## 限制與待辦

- 銀行通知規則只用合成樣本測過，需要使用者提供實際樣本來調整。
- 一萬筆效能測試（`app/test/perf`）已在優化輪補上：首頁與圖表的資料 81 ms、分析頁 275 ms。Golden 基準圖已在 GitHub 上重新產生。

## 2026-11-05 補強

- **「付款」分頁**：取代原本空白的「記帳」分頁。
  - 依月份列出全部付款紀錄，每月附合計，可只看單一項目，也可匯出 CSV。
  - 有待確認的通知辨識時，頂端會顯示提示。
  - 長按一筆付款可刪除，刪除後該期改回待付。
- **分期期數**：
  - 儲存時依「剩餘期數」（沒有時用「總期數」）從下一期算出最後一期日期，存在類型專屬欄位 `lastChargeOn`。
  - 最後一期之後不再展開扣款。方塊與詳情頁顯示「第 k/N 期」。
  - 全部付清後標示「已還清」，從首頁與月成本中移除。
- **信用卡出帳提醒**：還款類型設了結帳日，每月結帳日提醒「今天出帳 · X 日繳款」，通知上的「已付款」對應下一期。
- **通知辨識學習**：把待確認的扣款指派給某個項目後，記住通知上的商家名稱，存在項目的 `merchantNames`，隨項目同步；下次同一商家的通知會直接比對到該項目。
