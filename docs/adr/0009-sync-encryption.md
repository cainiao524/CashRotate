# 0009 同步加密與檔案格式

- 狀態：已採用（2026-10-30）
- 決策者：專案擁有者（要求「同步資料要小」「同步要快」）

## 決定

- **函式庫**：libsodium（經過審計、持續維護），透過 `sodium_libs` 套件呼叫。
- **加密**：XChaCha20-Poly1305 IETF。每個檔案用隨機的 24 bytes nonce；附加認證資料（AAD）是檔案在 WebDAV 上的相對路徑，檔案被搬到別的路徑就無法解密。
- **壓縮**：先用 gzip 壓縮再加密（密文無法壓縮），變更批次通常能縮小 70～90%。
- **金鑰衍生**：Argon2id，64 MiB、3 次（libsodium MODERATE 等級），鹽值 16 bytes，參數寫在 `manifest.json`。
- **速度**：Argon2id 只在首次設定同步或新裝置加入時執行一次。衍生出的金鑰存在 Android Keystore 包起來的本機儲存，之後每次同步都不重算，所以同步速度只取決於網路與檔案大小。
- **金鑰結構**：密碼經 Argon2id 衍生出「包裝金鑰」，用來加密一把隨機的「資料金鑰」，manifest 只存加密後的資料金鑰。復原碼是另一把包裝金鑰，也包著同一把資料金鑰，所以忘記密碼時可以用復原碼解開。之後改密碼只需重新包裝，不必重新加密雲端檔案。

## 檔案格式

`魔術字 "CRS1"（4 bytes）‖ nonce（24 bytes）‖ 密文（gzip 後的 JSON，含 16 bytes 認證標籤）`

格式版本寫在 manifest 和魔術字中，日後若要升級，以新版本號並存。
