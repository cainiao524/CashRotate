# 0013 同步與安全（M5）

- 狀態：已採用（2026-11-01）
- 決策者：專案擁有者選定函式庫、復原碼形式、App 鎖與備份方式；其餘由開發者依 CLAUDE.md 與 ADR 0009 實作

## 決定

- **函式庫**：
  - `sodium` 4.1.2（BSD-3 / libsodium ISC）：Argon2id 只在 sumo API 中提供，所以使用 `SodiumSumoInit`。
  - `local_auth` 3.0.2（Flutter 官方，BSD-3）：指紋 / 臉部解鎖。
  - WebDAV 用 `dart:io` 自己實作，不加套件。唯一的 WebDAV 套件從 2024 年起就沒有更新。
  - 建置需求：Windows 本機建置 Android 版時需要 Git Bash 與 `make`（`choco install make`）。另外要在 `gradle.properties` 關閉 Kotlin 增量編譯，因為 pub 快取和專案放在不同磁碟。
- **同步引擎**（`packages/sync`，純 Dart）：
  - 依 CLAUDE.md「同步」規則實作：欄位級合併、刪除用墓碑；刪除後另一台又修改時，放進待處理衝突。
  - 檔案先用暫存檔名上傳再 MOVE 改名。每台裝置在 `seen.json` 記錄自己合併到哪裡；所有裝置都合併過、而且已經包含在快照裡的變更檔，才會清除。保留最新 2 份快照。
  - 模擬測試：三台裝置隨機離線修改、時鐘偏差、亂序同步，25 組情境都收斂。
- **App 端**：
  - **同步範圍**：`DriftSyncStore` 只寫入白名單內的資料表和欄位，包括 `items`、`price_phases`、`occurrences`、`price_history`、`app_settings`、`exchange_rates`。寫入時先父表後子表。
  - **本機設定**：WebDAV 帳密和解開的資料金鑰只存在這台裝置的加密資料庫 `meta` 表，不同步。資料庫金鑰由 Keystore 保護。
  - **同步時機**：開啟 App、回到前景、本機變更停止 20 秒後，各同步一次。失敗只記在同步設定頁，不打斷使用者。
- **金鑰與復原碼**（照 ADR 0009）：
  - Argon2id 參數 64 MiB × 3，資料金鑰分別被密碼和復原碼包裝。
  - 復原碼可以讓 App 產生：160 位元，以 32 個 Crockford base32 字元表示，分 8 組。也可以使用自己的，例如 Bitwarden 產生的。自訂的復原碼至少 16 字元，強度估算約 100 位元以上才接受。
  - 首次設定時必須勾選「我已把復原碼存在安全的地方」。
- **App 鎖**：
  - 4～6 位數 PIN，用 Argon2id（libsodium interactive 參數）雜湊後只存在本機。可加上指紋 / 臉部解鎖，失敗時改用 PIN。
  - 連續錯 5 次後暫停 30 秒，之後每錯一次暫停時間加倍。
  - 離開 App 後重新鎖定的時間可選：立即、1 分鐘、5 分鐘。鎖定時 App 仍在背後執行，輸入到一半的內容不會遺失。
- **隱藏金額**：首頁眼睛按鈕；開啟後畫面上的金額顯示「••••」，通知內容也不帶金額。
- **本機備份**：
  - 每天自動備份一次，保留 7 份。用一把只存在本機資料庫的備份金鑰加密，可以選任一份還原。
  - **手動匯出**：`CRB1` 檔，用另外設定的密碼加密（Argon2id），透過系統的「儲存位置」選擇器存檔，不需要儲存權限。
  - **還原**：還原時取代同步範圍內的資料表，並把還原後的資料記成新的變更，被移除的資料列記墓碑，讓同步把還原結果帶到其他裝置，而不是被舊資料蓋回去。

## 限制與待辦

- 「待處理衝突」目前只能選「保持刪除」，還沒有「還原被刪的項目」。
- 鎖定時沒有設定 `FLAG_SECURE`，所以最近使用的 App 縮圖仍看得到內容（可在 M8 加上）。
- 首頁標題列的同步狀態圖示還沒做，目前在設定 › 同步與安全查看狀態。
- 尚未對 Nextcloud、群暉、堅果雲、InfiniCLOUD 實機測試。解析器已經用這幾家的回應格式測過。
- Argon2id 64 MiB 在低階手機上的耗時還沒量測（ADR 0009 要求上架前量測）。
