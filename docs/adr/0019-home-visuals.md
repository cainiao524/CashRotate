# 0019 首頁視效：字型、傾斜珠光、動態、同步時間

- 狀態：已採用（2026-11-12）
- 決策者：專案擁有者選定四個方向，依首頁設計稿（CLAUDE.md 介面一節）實作。

## 決定

- **字型 Manrope**
  - 用途：拉丁字母與數字照設計稿改用 Manrope；中文等其他文字仍用系統字型。
  - 來源與授權：Google Fonts 官方倉庫，SIL Open Font License 1.1。授權文字放在 `assets/fonts/Manrope-OFL.txt`，也登記在 App 的授權頁。
  - 字檔：Flutter 不會把 `FontWeight` 對應到可變字型的軸，所以用 fontTools 從可變字型切出 400、500、600、700、800 五個靜態字重，各約 97 KB，APK 只增加約 0.2 MB。
  - 字重調整：Manrope 的 Regular 筆畫比系統字型細，所以內文和標籤改用 Medium、標題用 SemiBold 或 Bold，維持原本的可讀性和對比。
- **珠光隨傾斜流動**（CLAUDE.md 的可選項）
  - 做法：用 Android 原生的重力感測器（`TiltStream`，事件頻道 `app.cashrotate/tilt`），不加套件。
  - 動畫：開場的光帶掃過之後，改為一道較柔和的光帶隨手機左右、前後傾斜移動。數值約每秒 30 次，並平滑過渡，不讓感測器的雜訊抖動顯現出來。
  - 省電：只在首頁總額卡顯示、App 在前景時才開啟感測器。系統開啟「減少動態」時完全不啟動。
- **微互動**
  - 方塊按壓縮放、倒數環和總額的過渡動畫本來就有。
  - 新增：往下捲動方塊時，「新增」按鈕會收成圓形，往回捲時再展開。
  - 新增按鈕改成設計稿的墨色膠囊，配柔和的低陰影。
- **標題列同步時間**
  - 雲朵圖示旁顯示「剛剛 / N 分鐘前 / N 小時前 / 日期」，每分鐘自動更新。
  - 同步進行中時圖示會轉動；「減少動態」時不轉。
  - 字級放大到 130% 以上時只顯示圖示，以免擠到標題。
- **無障礙修正**：首頁的「N 項」原本和整排工具列併成同一個朗讀節點，改成獨立節點，TalkBack 會單獨讀出它。
