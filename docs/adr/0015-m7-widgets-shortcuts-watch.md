# 0015 桌面小工具、App 捷徑與手錶（M7）

- 狀態：已採用（2026-11-04）
- 決策者：專案擁有者決定：
  - 小工具用 RemoteViews。
  - 手錶只鏡像通知。
  - M6 AI 匯入移到 backlog，M7 之後直接回頭優化。
  - 其餘由開發者依 CLAUDE.md 實作。

## 決定

- **範圍調整**：
  - CLAUDE.md 第 8、17 項、里程碑與執行順序已同步更新。
  - Wear OS 資訊卡 / 錶面小元件、AI 匯入都記在 `docs/backlog.md`。
- **桌面小工具**：Android 原生 `AppWidgetProvider` + RemoteViews，不加套件。
  - **三種大小**：
    - 小（2 × 2）：本月總額與下一筆。
    - 中（4 × 2）：加上已付 / 待付，以及 3 筆近期扣款。
    - 大（4 × 4）：再加上已付進度條，以及 6 筆近期扣款。
  - **內容由 App 提供**：
    - Dart 組好快照 JSON，文字和金額都已在 Dart 端格式化，經 `app.cashrotate/widgets` 交給原生端，存在 SharedPreferences。
    - 小工具不需要自己的翻譯字串，只有系統挑選器顯示的名稱放在 Android 資源（英 / 繁 / 簡）。
  - **剩餘天數由原生端計算**：
    - 快照只給到期日與複數模板，例如「In {n} days」。
    - 小工具每 3 小時重繪一次，每日補檢 Worker 也會重繪，所以過了午夜仍正確。
  - **隱藏金額模式**：小工具上的金額同樣顯示「••••」。
  - **樣式**：沿用珍珠單色色票，並有深色模式版本。名稱放不下時換行，不用省略號截斷。
  - **點擊**：點項目開啟該項目，點其他地方開啟 App。
- **App 捷徑**：
  - 「新增項目」「記一筆付款」用 `ShortcutManager` 動態捷徑設定，標籤跟著 App 目前語言。
  - 「記一筆付款」會先讓使用者選項目（依到期日排序），再開付款表單。
  - 開關是 `Features.appShortcuts`。
- **手錶**：
  - 手機上的提醒通知原本就不是只限本機，所以會鏡像到配對的 Wear OS 手錶。
  - 用 `WearableExtender` 指定手錶上只顯示「已付款」「延後」兩個按鈕，動作都在手機上執行。
  - 「前往取消」要開網頁，所以只留在手機。

## 限制與待辦

- 原生部分（小工具繪製、捷徑、手錶按鈕）已能編譯，但還沒在實機或手錶上驗證；自動測試只涵蓋 Dart 端的快照內容和捷徑流程。
- 小工具還沒有挑選器預覽圖：Android 12 以上會直接用版面當預覽，較舊系統顯示 App 圖示。
