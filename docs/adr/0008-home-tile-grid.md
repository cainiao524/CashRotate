# 0008 首頁方塊格

- 狀態：已採用（2026-10-30）
- 決策者：專案擁有者提供設計稿（https://claude.ai/artifact/LQR9XP6modWQJWETzbv5GA），細節由開發者判斷

## 決定

- **版面**：
  - 手機：精簡珠光總額卡 → 搜尋、排序、類型篩選列 → 3 欄方塊格，右下角有「新增」浮動按鈕。
  - 600–840dp：同上，改成 4 欄。
  - 平板（≥ 840dp）：6 欄。總額是 2×2 大磚（字體放大時改成 2×3），後面依序是項目方塊、本月收支寬磚、固定與變動寬磚，最後一格是「新增項目」。
  - 排列採第一個放得下的位置，讓單格方塊補進寬方塊留下的空位。
- **設定移出分頁**：底部導覽只剩首頁、固定支出、記帳、分析。手機從首頁標題列右上角進入設定；導覽軌把設定放在底部，頂部放「新增」。路由改為 `/home/settings`，返回鍵回到首頁。
- **總額卡**：
  - 大數字仍是每月平均成本：年繳攤提，和之前一樣。
  - 「待付」與已付進度條改用本月實際扣款：本月已付的金額，加上到月底仍待付的金額（含前幾個月逾期未付的）。所以年繳項目在扣款當月會以全額計入待付。
  - 平板分開列出已付、待付。
- **方塊**：
  - 金額是下一次扣款。外幣顯示「≈ 主要幣別」，原幣價格放在下方小字。
  - 小字依序列出：原幣價格、扣款日、非每月週期、分攤人數。
  - 特殊狀態只寫在小字裡，不另加標籤：逾期（紅）、改收新價（琥珀）、待補（琥珀）、已暫停、已取消（可用至某日）。
- **倒數環**：
  - 環長是本期已過的比例：從上一次扣款日算到下一次，最少 5%。
  - 超過 14 天時是灰色 #8E8E93。14 天內色相從 48° 漸變到 3°，深色方塊用較亮的那一組色。
  - 逾期時是紅色滿環，再加一段，長度 = 逾期天數 ÷ 週期天數，最多半圈。
  - 暫停或取消時只畫淡底環。
- **反白與逾期**：
  - 2 天內扣款的方塊反白（主色底、反色字）。
  - 逾期的方塊自動變成寬方塊，加上紅框和「已付款」按鈕（48dp 觸控範圍），按下會把那一期標為已付。
- **方塊設定**：長按方塊會開啟選單，可以切換寬方塊、選圖示、標為已付、查看詳情。設定頁另有「方塊使用服務代表色」開關。這些設定存在 `app_settings`，會隨同步帶到其他裝置：
  - `home_tile_colors`
  - `home_wide_tiles`：項目 id 清單
  - `home_tile_icons`：項目 id 對應內建圖示名稱
- **內建圖示**：30 個通用線條圖示（Material Icons，Apache-2.0），沒有任何品牌標誌。圖示名稱會寫進儲存的資料，所以不能改名。
- **字體放大**：
  - 列高依目前的字級計算。
  - 文字太多時從上方裁切，不讓方塊溢出（例如系統關閉動畫時，跑馬燈改為換行）。
  - 圓環中的數字和首字母是固定大小的圖形，螢幕閱讀器改讀方塊的完整描述。

## 與設計稿的差異（暫不做）

- 標題列的同步狀態和隱藏金額按鈕：M5 才有這兩項功能。
- 總額卡的月份切換：目前只顯示當月的月份文字。
- 與上月比較：需要歷史資料，M4 記帳上線後再做。
- 平板的搜尋、排序列在內容最上方，不和 App 名稱擠在同一行。
- 使用者上傳圖片當圖示：需要附件儲存與備份，排在 M5 之後。
- 平板的本月收支、固定與變動兩塊卡片：M4 之前只顯示「開始記帳後顯示」。
- Manrope / Noto Sans TC 字體：沿用目前的系統字體。要內嵌字體會增加 APK 大小，M7 再決定。
- 房貸的「第 14 / 240 期」：還款期數的欄位還沒做（還款類型專屬欄位）。
